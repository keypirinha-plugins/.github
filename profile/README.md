# Keypirinha - Launch Programs You Already Installed

At a glance:
- A box that finds apps on this PC
- Results from names you typed
- Plugins only after you know what they list
- Quit so the last search is not left visible

## A Name You Typed

Keypirinha opens when you press its hotkey and filters programs, folders, and files it is allowed to see for this user. Type a short name of something you installed and start it. If the result is not the program you meant, do not press enter. Look at the path in the result.

The catalog is this Windows user. It does not scan the network for computers, and it does not type for you in other apps except to launch what you chose. A hotkey that clashes with another tool can be changed. Change it rather than stacking two launchers on the same keys.

## Plugins You Enable

A plugin might search bookmarks, calculator input, or files. Read what it indexes before you enable it. A file plugin pointed at a whole disk will surface other people's documents on a shared PC. Point it at your project folder or leave it off.

Do not install a plugin from a random page because the box feels empty. The default list of installed programs is enough to prove the hotkey. Packages you add are code that runs in your session.

## What It Should Not Find

Passwords, mail stores, and other users' profiles are not launch targets. If a result shows a path you should not open, do not open it, and narrow the plugin. History of your queries can reveal what you searched. Clear it if the PC is shared, and quit the app when you leave.

## The Hotkey

Pick a shortcut you will not hit while typing a password. If the box appears over a banking page, close it before you continue. The launcher should not be the thing that captures a password you meant for the browser. It launches programs. It is not a place to store secrets.

## One Machine

Keypirinha does not remote-control another PC. If you wanted a program on a server, use a login you were given, not this box. A result that looks like a system tool still runs with your rights. Do not start a tool you cannot explain just because it matched a few letters.

## Queries You Clear

The box remembers what you typed. On your own desk that is a shortcut. On a shared desk it is a list of what you searched. Quit and clear it when you stand up. The installed programs remain either way.

## Help Desk

The wrong program starts? You confirmed too fast. Read the path next time.
A plugin shows other people's files? Disable it or point it at your folder only.
The hotkey opens over a password field? Close the box and change the shortcut.
Nothing is found? The program is not installed for this user. Do not download a random build from the search box.
You wanted another PC? This tool does not connect there.

## Reader Notes

The first day is the hotkey and one real program. Plugins wait. A launcher that searches too much becomes a list of files you did not mean to see.

History is a convenience on your own desk and a leak on a shared one. Quit and clear it when you stand up. The programs stay installed either way.

Keypirinha does not install software for you and does not audit the network. It opens what you choose after you have looked at the path.
